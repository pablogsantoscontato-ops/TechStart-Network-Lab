# TechStart Network Lab

## 📌 Sobre o projeto

Este projeto consiste na simulação de uma infraestrutura de rede corporativa utilizando o **Cisco Packet Tracer**.

O objetivo é aplicar conceitos fundamentais de redes de computadores, criando uma rede organizada, segmentada e preparada para crescimento.

O cenário representa uma empresa fictícia chamada **TechStart**, que precisa melhorar sua organização de rede separando seus departamentos e automatizando a configuração dos dispositivos.

---

## 🏢 Cenário da empresa

A TechStart é uma empresa em crescimento que possui diferentes setores:

* Financeiro
* Tecnologia da Informação (TI)
* Recursos Humanos (RH)
* Diretoria

Atualmente, todos os computadores estão na mesma rede, causando problemas de organização e gerenciamento.

A empresa solicitou uma nova estrutura de rede com:

* Separação dos departamentos.
* Organização dos endereços IP.
* Distribuição automática de IPs.
* Comunicação entre switches.
* Estrutura preparada para expansão.

---

## 🎯 Objetivos do projeto

* Criar uma rede corporativa simulada.
* Implementar segmentação utilizando VLANs.
* Configurar comunicação entre switches através de Trunk.
* Realizar planejamento de endereçamento IP utilizando VLSM.
* Implementar DHCP para distribuição automática de endereços IP.
* Testar a conectividade da rede.

---

## 🛠️ Tecnologias e conceitos utilizados

* Cisco Packet Tracer
* VLAN (Virtual Local Area Network)
* Trunk 802.1Q
* DHCP (Dynamic Host Configuration Protocol)
* Subnetting
* VLSM (Variable Length Subnet Mask)
* Modelo OSI
* TCP/IP

---

## 🌐 Estrutura da rede

A rede será dividida em diferentes VLANs:

| VLAN | Departamento |
| ---- | ------------ |
| 10   | Financeiro   |
| 20   | TI           |
| 30   | RH           |
| 40   | Diretoria    |

Cada departamento terá sua própria rede IP, permitindo uma melhor organização e gerenciamento dos recursos.
